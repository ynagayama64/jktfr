Chrome または Safari で開いてください

LINEなどのアプリ内ブラウザでは、
Googleログインが正常に動作しないことがあります。

右上メニューから
「Chromeで開く」「Safariで開く」を選んでください。

iPhone: 右上または下部メニューから Safari で開く

Android: 右上メニューから Chrome で開く

PC版LINE: 「ブラウザで開く」を選ぶか、URLをコピーして Chrome / Edge / Safari で開く

以下のページを開いた後、
学校のGoogleアカウントでログインしてください。

別のGoogleアカウントで開いている場合は、
学校アカウントへ切り替えてください。
